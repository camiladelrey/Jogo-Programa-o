# Missão Biomas 🌿

Quiz educativo de Ciências para estudantes do 6º ano do Ensino Fundamental (11 a 12 anos).

## Arquivos
- `index.html`: estrutura e conteúdo das telas.
- `style.css`: cores, layout, responsividade e acessibilidade visual.
- `script.js`: perguntas, respostas, pontuação, vidas e resultado.

## Como jogar
Clique em **Começar missão**, escolha uma das quatro alternativas e leia o retorno. Cada acerto vale 10 pontos. O jogador começa com três vidas; cada erro tira uma vida. A partida termina após as dez perguntas ou quando as vidas acabam.

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie estes três arquivos para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, selecione `main` e `/ (root)` e salve.
5. Aguarde a publicação e copie o endereço exibido pelo GitHub Pages.
6. Abra o link publicado e teste o jogo no computador e no celular.

**Link do repositório:** preencher depois de criar o repositório.  
**Link executável:** preencher depois de ativar o GitHub Pages.
